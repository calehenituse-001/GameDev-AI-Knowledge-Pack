# Referensi Eksternal: Awesome GameDev Agent Skills

Sumber: https://github.com/gamedev-skills/awesome-gamedev-agent-skills

Digunakan sebagai referensi format Agent Skills, router, panduan engine, dan praktik debugging. **Repositori ini bukan fork atau mirror otomatis.**

- Jumlah skill dan detailnya dapat berubah; cek commit serta README upstream.
- Jika menyalin/memodifikasi konten upstream yang memakai Apache-2.0, ikuti ketentuan lisensi, atribusi dan NOTICE yang diwajibkan.
- Panduan lokal ini adalah starter generik dan memerlukan verifikasi terhadap versi engine tertentu.
- Agent harus mendukung pembacaan SKILL.md agar routing otomatis bisa digunakan.
