# Kontribusi Panduan

## Boleh masuk
Panduan umum lintas proyek, checklist, template, referensi, dan Agent Skills reusable.

## Tidak boleh masuk
Source code/asset game spesifik, APK/ISO, save pribadi, access token, log privat, atau materi proprietary tanpa izin.

## Aturan kontribusi
1. Jelaskan tujuan dan cakupan engine/platform.
2. Hindari API yang belum diverifikasi; cantumkan versi dan sumber resmi bila perlu.
3. Pisahkan fakta yang sudah dites dari hipotesis.
4. Sertakan langkah uji serta rollback untuk instruksi yang mengubah sistem.
5. Hormati lisensi dan atribusi pihak ketiga.
6. Pertahankan sifat universal: proyek tertentu hanya dipakai sebagai contoh abstrak.

Gunakan versi v0.x untuk dokumen awal dan catat perubahan di commit/release.
