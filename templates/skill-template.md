# Template Skill Baru

Buat file skills/nama-skill/SKILL.md dengan format:

~~~yaml
---
name: nama-skill
description: Kapan skill ini relevan dan kapan perlu dipakai.
---
~~~

Isi setelah YAML frontmatter:

1. Tujuan umum dan ruang lingkup.
2. Prasyarat dan pembatasan versi.
3. Langkah investigasi.
4. Prosedur implementasi.
5. Pengujian, rollback, dan acceptance criteria.
6. Kesalahan umum dan sumber resmi.

Skill harus lintas proyek, tanpa file/path/aset game tertentu.
