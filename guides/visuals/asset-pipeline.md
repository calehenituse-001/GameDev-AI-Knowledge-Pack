# Pipeline Aset 2D dan 3D

## Arah seni
Tetapkan silhouette, proporsi, palet, referensi sudut pandang, tingkat detail, budget polygon/tekstur, dan style guide.

## 3D
Blockout → validasi skala/silhouette → topology → UV → material → rig/animasi → export → tes dalam engine.

## 2D
Referensi → canvas size → pivot → sprite/atlas → alpha/transparency → tes skala/resolusi.

## Validasi
Depan dan belakang harus konsisten; pivot tepat; normal dan mesh tidak rusak; transparansi dan UV tidak memperlihatkan artefak; elemen gameplay yang perlu bergerak tidak tergambar permanen di tekstur.

Catat asal aset, izin, dan atribusi.
