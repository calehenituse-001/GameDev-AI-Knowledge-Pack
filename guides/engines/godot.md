# Godot — Panduan Universal

Pastikan versi engine sebelum memilih GDScript API, node, atau resource.

- Gunakan scene tree untuk komposisi dan pahami lifecycle _ready, _process, serta _physics_process.
- Gunakan signal untuk coupling longgar.
- Bedakan CharacterBody, RigidBody, dan Area sesuai semantik physics.
- Simpan konfigurasi sebagai Resources/data yang tervalidasi.
- Saat multiplayer, verifikasi authority, RPC, synchronization, spawning, dan ownership.

Verifikasi: parse/import scene, path res://, signal connections, group, pivot/scale, renderer, export preset, input di perangkat Android/web, dan runtime logs.

Referensi: https://docs.godotengine.org/
