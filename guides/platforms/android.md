# Android — Panduan Universal Game

## Audit awal
Android API level, ABI arm64-v8a, engine backend, GPU/driver, permission, signing, dan distribusi.

## Integrasi
Uji lifecycle pause/resume, orientation, audio focus, keyboard/gamepad/touch, safe area, permissions, dan penyimpanan Android modern.

Bedakan Java/Kotlin crash (logcat) dari native crash (tombstone/backtrace). APK yang berhasil terinstal tidak otomatis berarti gameplay berfungsi.

## Performa & rilis
Uji GPU renderer, RAM, thermal throttling, texture compression, frame pacing, ukuran unduhan, upgrade tanpa merusak save, dan lisensi library.

Referensi: https://developer.android.com/games
